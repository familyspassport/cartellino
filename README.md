# Cartellino

Archivio vestiti del negozio: ogni capo ha un codice unico e una foto; cerchi il codice e appare il vestito.

- `index.html` — la pagina (GitHub Pages)
- `supabase/migrations/` — tabella, bucket foto e permessi
- `setup.sh` — setup completo: Supabase + login negozio + pubblicazione
- `staff.sh` — aggiunge un altro login (commessi)

Aggiornare la pagina dopo una modifica: `git commit -am "modifica" && git push`
